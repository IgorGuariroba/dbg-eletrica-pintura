# Ícones PWA

Substituir por ícones reais antes do deploy. Tamanhos esperados:

- `icon-192.png` — 192x192 (any)
- `icon-512.png` — 512x512 (any)
- `icon-maskable-512.png` — 512x512 (maskable, safe-zone respeitado)

Gerar a partir do logo DBG (ex.: https://realfavicongenerator.net ou `pwa-asset-generator`).
