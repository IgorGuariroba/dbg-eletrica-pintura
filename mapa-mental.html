Conexões entre Personas

Formulário → wa.me → Fila → Orçamento — cliente descreve, técnico orça, admin monitora

Link Único + Role Detection — mesmo link, Google = cliente, conta interna = técnico

Aprovação → Agendamento → Push — cliente aprova, admin agenda, técnico recebe push

Rastreio Bidirecional — técnico sinaliza status, cliente confirma presença

Conclusão → Upsell → Pagamento → Webhook — técnico conclui, cliente paga, sistema atualiza

Notificação Multicanal — WhatsApp sempre + e-mail se Google vinculado

Garantia → Chamado → OS — cliente aciona, sistema valida, técnico corrige

Rastreio Total → Dados — toda interação vira ativo de dados pra insights
