# wa.me para abrir conversa, Cloud API para notificações proativas

Dois mecanismos de WhatsApp com propósitos distintos. wa.me (links grátis) para ações iniciadas pelo usuário: formulário → empresa, técnico → cliente. Cloud API (1.000 conversas/mês free) para mensagens proativas do sistema: orçamento pronto, técnico a caminho, lembrete pagamento, remarketing, avaliação.

Decidimos assim porque: (1) Cloud API tem custo por conversa após 1.000/mês — usar só pra ação imediata otimiza custo; (2) documentação (fatura, garantia, fotos) vai por e-mail (Resend, grátis) em vez de WhatsApp; (3) notificações respeitam horário 8h-20h pra não incomodar, com fila de envio. Pré-requisito: migrar número (11) 95236-0688 de pessoal para WhatsApp Business verificado.
