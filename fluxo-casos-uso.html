1. Chega na Landing Page

Acessa o site via Google, indicação ou link direto. Vê serviços oferecidos, portfólio antes/depois, avaliações reais e CTA principal: "Descreva seu problema e receba um orçamento".

Landing Page

2. Preenche Formulário de Solicitação

Formulário de taps — mínimo de digitação. WhatsApp (único campo digitado), categorias em cards visuais (Elétrica / Pintura / Drywall — múltipla seleção permitida), fotos opcionais (botão câmera/galeria), data desejada (date picker), duração estimada (chips: <1h / meio dia / dia inteiro / +1 dia / não sei), descrição por áudio (transcreve via Web Speech API) ou texto livre opcional. Endereço obrigatório, método de input opcional: compartilha localização atual (Geolocation API + BrasilAPI pra geocoding reverso, 1 tap), ou digita CEP (ViaCEP preenche rua, bairro, cidade; resta só número e observação), ou digitação manual (último recurso). Mínimo obrigatório: CEP + número. Antes do envio: checkbox LGPD com link pra política de privacidade e termos (finalidade explícita dos dados, direito de exclusão). Sem aceite, não envia. Envio cria 1 Solicitação (pode gerar N ordens de serviço — 1 por categoria/especialidade). Usuário criado pelo número — sem senha, sem login.

Formulário Low-Friction + LGPD

3. Confirmação + Envio via WhatsApp (wa.me)

Formulário enviado → tela de confirmação no site: "Solicitação #XXX criada" com link da solicitação. Em seguida, redireciona pro WhatsApp da empresa via wa.me com mensagem pré-preenchida (dados do form + link). wa.me = abrir conversa (grátis, sem API). Cliente sabe que foi registrado mesmo se atendimento humano demorar. Mesmo link pra todos — role detection por cadastro no banco.

Confirmação + wa.me

4. Acesso ao Site (com ou sem Google)

Cada solicitação tem URL única: site.com/s/{token}. Dois modos de acesso: (A) Sem login (token) — versão limitada: aprovar/rejeitar orçamento, ver status, avaliar, acionar garantia. Ações sensíveis (aprovar orçamento) = token + código de verificação via WhatsApp. Dona Maria funciona 100% por WhatsApp + links. (B) Com Google OAuth — portal completo: histórico de todas OS, múltiplas solicitações, faturas, documentos, link de indicação sempre acessível. Primeiro Google a acessar vincula ao número do form. Outro Google → bloqueado. Admin pode desvincular Google no módulo Equipe (edge case: vinculação errada). Role detection: e-mail na tabela de membros → visão técnico/admin. Senão → visão cliente.

Token + Google OAuth

5. Recebe Orçamento Digital

Técnico monta orçamento no link da solicitação (breakdown: material + mão de obra + deslocamento). Notificação multicanal: WhatsApp sempre + e-mail se Google vinculado. Orçamento válido por 7 dias — lembrete automático no dia 3 e dia 6. Sem resposta no dia 7 → expira e entra no remarketing. Toda comunicação registrada no sistema — ativo de dados pra insights e melhorias.

Orçamento 7 dias + Rastreio

6a. Aprova Orçamento ✓

Aprova no app com assinatura digital. Sistema libera agendamento — escolhe data e horário disponíveis.

6b. Rejeita Orçamento ✗

Rejeita com motivo opcional. Solicitação encerrada. Histórico salvo no portal. Remarketing 48h: WhatsApp (sempre disponível) + e-mail (se Google vinculado).

7. Agendamento após Aprovação

Orçamento aprovado → sistema filtra técnicos por especialidade + disponibilidade automaticamente → cliente escolhe data e horário entre slots vagos (não escolhe técnico). Técnico atribuído automaticamente pelo sistema. Admin pode reatribuir se necessário (módulo Operação). Perfil do técnico designado acessível (foto, nome, bio, especialidades, avaliações, portfólio) — disponível se quiser ver, não obrigatório.

Instant Booking Híbrido

8. Reagendamento / Cancelamento

Três atores podem reagendar/cancelar com regras diferentes: (1) Cliente — até 24h antes, sem taxa, pelo site ou WhatsApp. Dentro de 24h → bloqueado no sistema, tela redireciona pra wa.me do admin (decide caso a caso). Notifica técnico + admin. (2) Técnico — pode reagendar OS atribuída a ele. Cancelar só com motivo obrigatório (auditoria). Notifica cliente + admin. (3) Admin (módulo Operação) — pode reagendar/cancelar qualquer OS, inclusive em lote ("cancelar todas de hoje"). Notifica todos envolvidos. Cancelamento libera slot automaticamente (volta pro instant booking). Reagendamento abre nova seleção de slot. Histórico de alterações + motivos registrado na solicitação.

Reagendamento Multi-Ator

9. Acompanha Status do Técnico

Técnico sinaliza "a caminho" → cliente notificado (WhatsApp + e-mail se Google vinculado). Cliente confirma presença no link da solicitação. Técnico vê confirmação na visão interna + botão wa.me pra contato direto com cliente (abre WhatsApp com número pré-preenchido, 1 tap). Se cliente não está, evita viagem perdida.

Rastreamento + wa.me

10. Conclusão + Pagamento com Upsell

Técnico tira foto do serviço finalizado, registra observações/resolução e confirma conclusão. Pagamento só para OS paga (Normal, Express, Complementar) — OS Preventiva e Garantia terminam em CONCLUÍDA sem pagamento. Checkout consolidado opcional: cada OS gera link individual. Se múltiplas OS concluídas na mesma solicitação, checkout mostra opção "pagar tudo junto" com total consolidado — cliente escolhe. Nenhuma OS bloqueia pagamento de outra. Antes do pagamento: upsell de assinatura com economia visível — só se cliente não é assinante (aparece uma vez só) + social proof. Cliente pode adicionar assinatura e pagar tudo junto (serviço + primeira mensalidade) via Mercado Pago (Pix ou cartão). Descontos de assinante aplicados por OS. Webhook atualiza status e ativa assinatura automaticamente. Alternativa: pagamento manual (dinheiro, transferência) — técnico confirma recebimento na plataforma e registra forma de pagamento. Se Pix expira ou cartão recusa: lembrete WhatsApp dia 1 e dia 3, novo link gerado automaticamente.

Checkout Consolidado + Upsell

11. Recebe Garantia Formal

Certificado de garantia de mão de obra gerado automaticamente em PDF. Prazo definido por tipo de serviço (ex: Elétrica 12 meses, Pintura 6 meses). Na OS concluída e no certificado: botão "Acionar Garantia" visível enquanto prazo válido. Ao clicar: mini-formulário (descrição do problema + foto obrigatória). Sistema valida prazo automaticamente. Se existe Orçamento Complementar rejeitado na OS original → sistema sinaliza pro admin (módulo Garantias) com detalhes. Admin decide se garantia se aplica (correspondência problema-complementar = julgamento humano). Se não se aplica → admin marca com motivo, cliente recebe aviso com contexto. Se válido → OS original transita pra GARANTIA_ABERTA (estado terminal) e sistema gera nova OS tipo GARANTIA sem custo.

Garantia + Validação Inteligente

12. Recebe Documentação

Fatura, fotos antes/depois, certificado de garantia — tudo gerado em PDF com layout profissional. Arquivos em Cloudflare R2 (10 GB free, zero egress). URLs assinadas pra acesso privado — fotos de OS não são públicas. Portfólio aprovado = cópia pública separada. Notificação por prioridade: WhatsApp pra ação imediata, e-mail (Resend) pra documentação PDF. Documentos acessíveis no portal a qualquer momento.

Documentação + R2

13. Avalia o Serviço

Recebe pedido de avaliação multicanal (WhatsApp + e-mail se Google vinculado) com link direto pra avaliar no site. Nota por OS (não por Solicitação): tela única agrupa todas as OS — cliente avalia cada uma separadamente (estrelas individuais) + comentário geral opcional. Cada nota vinculada à OS e ao técnico responsável. Se não avalia, lembrete único 48h depois — sem insistir. Se todas as notas ≥ 4★, recebe link direto para avaliar no Google Business + link de indicação (referral). Reputação da empresa cresce organicamente.

Avaliações + Google Business + Indicação

14. Portal — Histórico e Faturas

Área logada: lista de todas as solicitações (múltiplas simultâneas permitidas) com status individual. Histórico de OS, fotos antes/depois, faturas, certificados de garantia, garantias ativas. Tudo documentado, tudo acessível.

Portal do Cliente

15. Plano de Manutenção (opcional)

Três canais de assinatura: (1) Checkout digital — upsell com economia visível antes do pagamento (só se não é assinante), cliente adiciona sozinho. (2) Presencial — técnico seleciona plano no PWA, mostra detalhes na tela, cliente assina na tela do técnico (aceite formal registrado como "assinatura presencial"). (3) QR na hora — cliente escaneia QR que leva direto pra página de assinatura. Todos os canais: visitas preventivas, desconto em serviços, prioridade no agendamento. Cobrança mensal automática via Mercado Pago. E-mail de boas-vindas com benefícios, desconto %, próxima visita preventiva, data de cobrança. Upgrade: efetivo imediato, diferença proporcional cobrada (portal ou admin). Downgrade: efetivo no fim do ciclo pago. Cancelamento: efetivo no fim do ciclo — preventivas dentro do ciclo acontecem, após efetivação sistema cancela preventivas futuras automaticamente.

Remoto

R1. Acessa Painel do Técnico

Loga com Google OAuth — sistema reconhece como técnico pelo e-mail cadastrado. Três visões: (1) OS atribuídas — agenda do dia, OS já agendadas pra ele. (2) OS abertas sem atribuição — fila geral filtrada por especialidade do técnico (só vê categorias que tem cadastradas). Pode se atribuir a uma OS e montar orçamento — sem precisar de módulo Operação. Pode devolver OS antes de montar orçamento (estado NOVA) com motivo breve obrigatório — OS volta pra fila. Depois de orçar (ORÇADA+), só cancela com motivo completo. (3) Link direto — recebe link de solicitação específica (via notificação ou admin). Toda interação pela plataforma: orçamentos, status, notas. Nada por fora.

Painel + Self-Assign

R2a. Orçamento Remoto ✓

Info do formulário suficiente. Seleciona itens do catálogo (preço base × quantidade = total). Envia orçamento ao cliente pelo sistema. Cliente aprova pelo link (assinatura digital) → agenda slot → técnico recebe notificação.

R2b. Visita Técnica ✦

Info insuficiente pra orçar remotamente. Técnico agenda visita de avaliação. No local: tira fotos melhores, descreve problema real, monta orçamento presencial. Cliente pode aprovar ali (assinatura na tela, dois checkboxes: LGPD + orçamento) ou receber link pra aprovar depois (fluxo remoto normal, 7 dias).

R3. Recebe Notificação de Agendamento

Cliente aprovou e agendou → técnico recebe notificação no painel interno + push no PWA. Vê data, horário, endereço, detalhes do serviço. Agenda do dia atualizada automaticamente. Se visita técnica com aprovação presencial e serviço simples, técnico pode executar na hora — estados de deslocamento da visita ficam no histórico (aconteceram de verdade), OS transita APROVADA → EM_EXECUÇÃO direta (permitido quando técnico já está NO_LOCAL). OS continua tipo NORMAL. Reagendamento/cancelamento: antes de A_CAMINHO → reagenda livre (novo slot). Depois de A_CAMINHO → motivo obrigatório. Cancelamento sempre com motivo — OS volta pra fila (AGENDADA sem técnico) pra reatribuição. Em execução: não cancela, cria OS Complementar ou registra motivo como metadado "aguardando complementar".

P1. Recebe OS Preventiva na Agenda

Sistema gera OS tipo PREVENTIVA automaticamente pelo calendário do plano de assinatura (Básico: 1/semestre, Conforto: 2/semestre, Premium: 4/ano). Técnico recebe na agenda com status AGENDADA. Sem orçamento — coberta pelo plano. Admin/cliente pode reagendar.

Geração Automática

P2. Desloca + Foto Antes

P3. Segue Checklist Preventivo

Checklist por Categoria

P4. Relatório + OS Complementar

PWA Offline

C2. Orçamento Complementar (se necessário)

Descobriu serviço adicional não previsto (ex: fiação precisa trocar)? Técnico monta orçamento complementar direto na mesma OS pela plataforma. Gera OS tipo COMPLEMENTAR vinculada à OS pai. Aprovação depende da presença: cliente no local → assina na tela do técnico (aprovação presencial), OS Complementar pula pra EM_EXECUÇÃO. Cliente ausente → notificação multicanal. Técnico continua escopo original ou registra motivo "aguardando complementar" como metadado na OS (se não pode continuar sem aprovação). Não existe estado PAUSADA. Se cliente aprova remotamente → OS Complementar vai pra APROVADA → agendamento normal (prioriza técnico original, não garante). Deslocamento na OS Complementar com aprovação remota = decisão do admin caso a caso. Valor adicional somado ao checkout final.

Técnico pode marcar foto como "boa pra portfólio" no PWA → admin (módulo Marketing) aprova antes de publicar. Nenhuma foto vai pro público sem aprovação. Fotos internas da OS ≠ fotos públicas.

PWA Offline + Camera API

Toca "Concluir". OS vai pra CONCLUÍDA. Pra OS sem custo (Preventiva, Garantia): fluxo termina aqui — pula direto pra avaliação (C6). Dados sincronizam quando voltar online.

Conclusão

C5. Pagamento Flexível + Upsell (só OS paga)

Só pra OS paga (Normal, Express, Complementar). Antes do pagamento: PWA mostra upsell de assinatura com economia visível — só se cliente não é assinante (aparece uma vez só, mesma mecânica do checkout digital). Cliente pode adicionar — técnico mostra tela, cliente assina (aceite presencial). Pagamento flexível: (A) Na hora — técnico mostra QR Pix na tela do PWA, cliente paga ali (serviço + primeira mensalidade se assinou). Ou pagamento manual (dinheiro/transferência) → técnico confirma recebimento na plataforma. (B) Depois — sistema gera link de pagamento, envia pro cliente via WhatsApp/e-mail. Pagamento nunca obrigatório pra concluir OS. Dados sincronizam quando voltar online.

Pagamento + Upsell + Sync

C6. Avaliação Automática

Sistema envia pedido de avaliação ao cliente automaticamente após conclusão. Nota por OS, tela única (mesma mecânica do passo 13 do cliente). Técnico acumula nota e portfólio (fotos antes/depois) no perfil.

Máquina de Estados — Ordem de Serviço

Tipos de OS

NORMAL (formulário remoto, pago, fluxo completo) · EXPRESS (técnico cria no local, pago, pula agendamento) · COMPLEMENTAR (extra descoberto, pago, vinculada a OS pai) · PREVENTIVA (sistema automático por plano, sem custo, recorrente) · GARANTIA (cliente aciona, sem custo, vinculada a OS original). Todos usam mesma máquina de estados.

Fluxo Principal

NOVA → ORÇADA → APROVADA → AGENDADA → A_CAMINHO → NO_LOCAL → EM_EXECUÇÃO → CONCLUÍDA → PAGA

Caminhos Alternativos

ORÇADA → REJEITADA (cliente rejeita) · ORÇADA → EXPIRADA (7 dias sem resposta) · Qualquer estado → CANCELADA (cliente até 24h antes, técnico com motivo, admin qualquer momento)

Garantia

PAGA → GARANTIA_ABERTA (estado terminal da OS original). Sistema gera nova OS tipo GARANTIA (sem custo): AGENDADA → A_CAMINHO → NO_LOCAL → EM_EXECUÇÃO → CONCLUÍDA. Validação de prazo = automática. Correspondência com complementar rejeitado = decisão humana (admin sinalizado).

Caminhos por Tipo

NORMAL: NOVA → ORÇADA → APROVADA → AGENDADA → A_CAMINHO → NO_LOCAL → EM_EXECUÇÃO → CONCLUÍDA → PAGA. EXPRESS: NOVA → ORÇADA → APROVADA → EM_EXECUÇÃO → CONCLUÍDA → PAGA. COMPLEMENTAR (presencial): idem Express. COMPLEMENTAR (ausente): idem Normal. PREVENTIVA: AGENDADA → ... → CONCLUÍDA (sem PAGA). GARANTIA: idem Preventiva. Transição APROVADA → EM_EXECUÇÃO direta permitida quando técnico já está NO_LOCAL.

Transições (não são estados)

Reagendamento = AGENDADA → AGENDADA (novo slot). Cancelamento libera slot automaticamente. Orçamento complementar: técnico continua escopo original ou registra metadado "aguardando complementar" em EM_EXECUÇÃO (não existe estado PAUSADA). Express sem aprovação presencial: OS fica ORÇADA, tipo continua EXPRESS, aprovação remota → agendamento normal se técnico não está mais no local.

Quem muda estado

Sistema: NOVA, EXPIRADA, AGENDADA (auto). Cliente: APROVADA, REJEITADA, GARANTIA_ABERTA (terminal, gera OS GARANTIA nova), CANCELADA. Técnico: ORÇADA, A_CAMINHO, NO_LOCAL, EM_EXECUÇÃO, CONCLUÍDA, CANCELADA (com motivo). Admin: qualquer transição (override). Sistema/Técnico: PAGA (webhook MP ou confirmação manual).

Integrações entre os Fluxos

Solicitação → OS → Orçamento

Cliente preenche form (múltiplas categorias permitidas) → wa.me envia pro WhatsApp da empresa com link → 1 Solicitação gera N ordens de serviço automaticamente (1 por categoria). 1 OS = 1 categoria = 1 técnico = 1 garantia (sem merge). Mesmo que um técnico faça tudo, são OS separadas. Cliente vê solicitação com OS filhas agrupadas no portal. Checkout consolida (paga tudo junto ou separado por OS).

Aprovação → Agendamento → Técnico

Cliente aprova orçamento → agenda data/horário → técnico recebe notificação push no PWA + painel interno atualizado

Link Único — Role Detection

Mesmo link da solicitação pra todos. Google login = visão cliente (leitura). Conta interna = visão técnico (edição). Primeiro Google vira dono.

Conclusão → Upsell → Pagamento

Técnico conclui + foto → checkout com upsell de assinatura → Mercado Pago (Pix/cartão) ou pagamento manual confirmado pelo técnico → webhook atualiza status

Notificação por Prioridade

WhatsApp (Cloud API) pra ação imediata: orçamento pronto, técnico a caminho/chegou, lembrete pagamento, remarketing, avaliação. E-mail (Resend) pra documentação: fatura PDF, fotos antes/depois, certificado garantia, resumo mensal assinante, boas-vindas assinatura. Otimiza custo Cloud API sem sacrificar experiência. Status visível no portal se logado.

Orçamento Complementar

Técnico descobre serviço adicional no local → monta orçamento complementar (OS tipo COMPLEMENTAR, vinculada a OS pai). Cliente presente → aprova na tela, pula pra EM_EXECUÇÃO. Cliente ausente → notificação, se aprova → APROVADA → agendamento normal (prioriza técnico original, não garante; deslocamento = decisão admin caso a caso). Se rejeita → REJEITADA (registro na OS pai = proteção garantia). Valor somado ao checkout.

Conclusão → Garantia + Documentação

OS concluída → gera certificado de garantia PDF + fatura + fotos antes/depois → enviado multicanal (WhatsApp + e-mail). Botão "Acionar Garantia" visível enquanto prazo válido.

Avaliação → Google Business

Cliente avalia ≥ 4★ internamente → recebe link direto pro Google Review. ≤ 3★ → admin trata antes. Lembrete único 48h se não avaliou.

Remarketing + Expiração

Orçamento expira em 7 dias (lembretes dia 3 e 6). Rejeição → remarketing 48h. Inativos 6+ meses → reativação. Tudo multicanal.

Garantia → Chamado → OS

Cliente clica "Acionar Garantia" na OS → descrição + foto → sistema valida prazo → se válido, abre OS de correção sem custo automaticamente

Rastreio Total → Dados

Toda interação registrada no sistema: orçamentos, decisões, pagamentos, avaliações → ativo de dados pra insights de marketing, campanhas, padrões de demanda e melhorias

Assinatura → Prioridade + Desconto

Cliente assinante recebe desconto automático no checkout e prioridade no agendamento. Upsell oferecido antes do pagamento com economia visível.
